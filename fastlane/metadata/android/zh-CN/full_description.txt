云析（YunX）是一个开源的安卓网盘 / 视频解析下载工具：粘贴分享链接，直接高速下载。

功能
- 网盘分享链接解析：识别夸克 / UC / 迅雷 / 百度 / 139 / 123 / 115 / 光鸭 / 蓝奏云 / 蓝奏云优享版 的分享链接，自动匹配提取码
- 视频链接解析：抖音 / 小红书 / 快手 / 微博 / AcFun 免登录直出直链；哔哩哔哩登录后画质更高，Pixiv 未登录只能拿到部分公开作品、登录后可解析全部作品，哔哩哔哩的音视频分轨由应用内部合轨
- 高速下载：Range 分片并发 + 断点续传，任务保存请求头与固定分片规划，并发上限 32
- 在线预览与播放：图片 / 视频 / 音频直接在线播放（逐请求带上 Referer / Cookie）；网盘里的常见文本文件也能在线打开
- 图集两列网格：图文笔记直接把图铺成两列，点开可翻页 / 双指放大 / 单张下载，长按可多选批量下载
- 下载自动归组：整个文件夹、或一次批量下载的图片，在下载页收纳成一个可折叠分组
- 临时转存清理：百度 / 迅雷取链后清理；夸克保留到下载完成或删除任务后清理
- 多平台登录：夸克 / UC / 百度 / 139 / 115 使用 WebView Cookie；迅雷使用密码 / 短信；123 使用账号密码换取 JWT
- 认证备份：使用用户口令派生密钥，以 AES-GCM 加密 Cookie / JWT 备份文件
- 剪贴板识别：复制分享链接后回到应用，提示一键粘贴解析

支持平台
网盘：夸克网盘、UC 网盘、迅雷网盘、百度网盘、123 云盘、139 网盘（和彩云）、115 网盘、光鸭云盘、蓝奏云、蓝奏云优享版
视频 / 图集：抖音、小红书、快手、微博、AcFun、哔哩哔哩、Pixiv

使用步骤
1. 在「账号」页登录需要使用的网盘账号（需要登录的视频平台也在这里登录）
2. 在「解析」页粘贴链接（可带提取码）：分享链接解析网盘，视频链接会自动识别平台
3. 网盘链接浏览分享内容、点击文件获取下载直链；视频链接在结果页直接预览或下载，图片笔记长按可多选
4. 在「下载」页查看进度，支持暂停 / 继续 / 删除 / 打开

运行要求
Android 7.0（API 24）或更高版本。

隐私与广告
应用内不含广告与统计 SDK；下载直链、Cookie 与 JWT 只保存在本机，认证备份文件使用用户口令派生的密钥加密。

提醒
不建议使用百度网盘，可能触发账号风控。云析永远免费开源：任何「收费版本」都是二次打包的诈骗包，与本项目无关。
